# cybersecurity-portfolio
This branch contains my **Splunk cybersecurity projects**, where I analyze security logs, detect threats, and create dashboards and alerts.  

##  Project Overview  
This project includes:  
-  **Log analysis**: Searching through security logs using **Splunk SPL queries**  
-  **Dashboard creation**: Visualizing security events  
-  **Alerts setup**: Configuring Splunk alerts for suspicious activity  
-  **Threat hunting**: Analyzing logs for security insights  

##  Files in This Branch  
- **The PDF file** contains:  
  -  **Two exercises** on security data analysis  
  -  **Splunk queries** used for investigation  
  -  **Screenshots** of dashboards, searches, and alerts  
  -  **Findings & interpretations**  

##  Data Source  
- The analysis was performed using **zip data from [secrepo.com and docs.splunk.com]**, ingested into Splunk for security monitoring.  

##  Skills Demonstrated  
- Writing **Splunk SPL queries**  
- Creating **dashboards & alerts**  
- Performing **log analysis** for cybersecurity  
- Threat hunting using real-world data
